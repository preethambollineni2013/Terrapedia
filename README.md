# Terrapedia

Terrapedia is an interactive encyclopedia about countries and history. When you search for a topic, it pulls information from multiple sources and uses **Chronos** (a self-designed AI) to write a clean summary for you. It also features an interactive 3D globe to explore the world.

**Live Demo:** [Terrapedia on GitHub Pages](https://preethambollineni2013.github.io/Terrapedia/)

## What It Does
* **Smart Summaries:** Searches different sources for the country or historical topic you look up and summarizes the facts using Chronos.
* **3D Globe:** Lets you explore locations visually right in your browser.
* **Hidden Easter Egg:** I added a secret Easter egg because I like Easter eggs. I'm not giving it away here—you'll have to look through the code or explore the site to find it!

## How to Run It Locally
Since this project is built with HTML,CSS,JS you don't need to install any complicated tools or servers to run it:

1. Download or clone all the project files into a single folder on your computer.
2. Double-click `index.html` to open it in your web browser.

**Note on Internet Access:** You will need an active internet connection for the 3D globe to load the Cesium library and satellite imagery, as well as to fetch live source info. Everything else works offline.


* **3D Globe:** Powered by [CesiumJS](https://cesium.com/platform/cesiumjs/)
  
* **Imagery & Facts:** Varies by topic and is summarized directly from the respective source providers.
